## Key findings (2026)

**Protocols**
- **MCP's current spec revision is `2026-07-28`** ("stateless protocol core": MRTR, header routing, cacheable list results, formal extension framework). Prior revisions: `2025-11-25`, `2025-06-18`, `2025-03-26`, `2024-11-05` — source: https://modelcontextprotocol.io/specification/ and its changelog (fetched 2026-10-08). GitHub release tag `2026-07-28` published 2026-07-28T16:47:49Z.
- MCP went **stateless** in 2026: the `initialize` handshake, `Mcp-Session-Id` sessions, SSE resumability, `ping`, `logging/setLevel` and `roots/list_changed` were removed, replaced by per-request `_meta` (`io.modelcontextprotocol/protocolVersion`, `clientCapabilities`), a mandatory **`server/discover`** RPC and a long-lived **`subscriptions/listen`** stream (SEP-2575). Roots/Sampling/Logging are **deprecated** with a ≥12-month window (SEP-2577/2596) — https://modelcontextprotocol.io/specification/2026-07-28/changelog (fetched 2026-10-08).
- MCP is **no longer Anthropic-owned**: donated 2025-12-09 to the **Agentic AI Foundation (AAIF)**, a Linux Foundation directed fund co-founded by Anthropic, Block and OpenAI (support: Google, Microsoft, AWS, Cloudflare, Bloomberg) — https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation , https://aaif.io/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation-aaif-anchored-by-new-project-contributions-including-model-context-protocol-mcp-goose-and-agents-md/ (fetched 2026-10-08).
- MCP scale (provider-published): **>10,000 active public servers and 97M+ monthly SDK downloads** (2025-12-09); **~500M Tier-1 SDK downloads/month with TypeScript and Python SDKs past 1B total downloads** (2026-07-28) — sources as above + https://blog.modelcontextprotocol.io/posts/2026-07-28/ (fetched 2026-10-08).
- **A2A reached v1.0.0 on 2026-03-12** (v1.0.1 on 2026-05-28) and **moved under the AAIF on 2026-08-17** (150+ partner organizations). IBM/BeeAI's competing **Agent Communication Protocol (ACP) merged into A2A in Aug 2025** (repo archived 2025-08-27) — https://api.github.com/repos/a2aproject/A2A/releases , https://aaif.io/blog/a2a-joins-aaif , https://github.com/i-am-bee/acp (fetched 2026-10-08).
- **Agent payments fragmented and then re-consolidated at FIDO**: Google's **AP2 v0.2.0 (2026-04-28)** was contributed to the **FIDO Alliance on 2026-04-28** (Agentic Authentication TWG chaired by CVS Health, Google, OpenAI); Stripe published the **Machine Payments Protocol (MPP, 2026-03-18)**; Google+Shopify launched the **Universal Commerce Protocol (UCP, Jan 2026)**, which is explicitly AP2-compatible; OpenAI+Stripe's **Agentic Commerce Protocol** (agenticcommerce.dev) remains the ChatGPT checkout standard — https://fidoalliance.org/fido-alliance-to-develop-standards-for-trusted-ai-agent-interactions/ , https://stripe.com/blog/machine-payments-protocol , https://ucp.dev/documentation/ucp-and-ap2/ , https://agenticcommerce.dev/ (fetched 2026-10-08).
- **"ACP" is genuinely ambiguous** across three live specs: Agent Communication Protocol (IBM/BeeAI, retired into A2A), **Agent Client Protocol** (Zed, editor↔coding-agent, 4,391★) and **Agentic Commerce Protocol** (OpenAI/Stripe). ## 1. Protocols & standards — status 2026-10-08

### 1.1 MCP (Model Context Protocol) — Anthropic → Agentic AI Foundation (Linux Foundation)
- **Canonical:** https://modelcontextprotocol.io/specification/ · spec repo https://github.com/modelcontextprotocol/modelcontextprotocol (**9,406★**, pushed 2026-10-08) · blog https://blog.modelcontextprotocol.io/
- **Current revision: `2026-07-28`** (site banner "Version 2026-07-28 (latest)"). GitHub release tag `2026-07-28` published **2026-07-28T16:47:49Z**. Revision history from the repo's releases: `2026-07-28`, `2025-11-25` (2025-11-25T21:17:42Z), `2025-06-18`, `2025-03-26`, `2024-11-05`.
- **2025→2026 transport change.** Streamable HTTP landed in `2025-03-26`; the Transport WG's plan ("Exploring the Future of MCP Transports", **2025-12-19**) set the stateless direction; it shipped in `2026-07-28`:
  - **Stateless core** — removed `initialize`/`notifications/initialized` handshake, protocol-level sessions and `Mcp-Session-Id`; every request carries version + client capabilities in `_meta`; new mandatory **`server/discover`** RPC; `UnsupportedProtocolVersionError` on mismatch (SEP-2575, SEP-2567).
  - **Multi Round-Trip Requests (MRTR)** replace server-initiated `roots/list` / `sampling/createMessage` / `elicitation/create` with `InputRequiredResult` (`resultType: "input_required"`) + `inputResponses` on retry; every result now has a required `resultType` (SEP-2322).
  - **Subscriptions**: HTTP GET endpoint + `resources/subscribe`/`unsubscribe` replaced by one long-lived **`subscriptions/listen`** POST stream; SSE resumability/`Last-Event-ID` and message redelivery removed.
  - **Removed/deprecated**: `ping`, `logging/setLevel`, `roots/list_changed`, URL-mode `notifications/elicitation/complete`. Roots, Sampling and Logging are **Deprecated** (SEP-2577); legacy **HTTP+SSE transport** reclassified Deprecated (SEP-2596); official deprecation policy = **minimum 12-month window**.
  - **Routing/caching/observability**: required `Mcp-Method`/`Mcp-Name` headers + `x-mcp-header` (SEP-2243); `ttlMs` + `cacheScope` on list/read results (SEP-2549); deterministic `tools/list` ordering for prompt-cache hits; OpenTelemetry trace-context keys in `_meta` (SEP-414).
  - **Tasks moved out of core** into official extension `io.modelcontextprotocol/tasks` (polling `tasks/get`, new `tasks/update`, no `tasks/list`) (SEP-2663).
- **Auth.** Core auth is **OAuth 2.1**; 2026 hardening: `iss` parameter per RFC 9207 must be validated (SEP-2468), `application_type` required in DCR (SEP-837), credentials bound to issuing authorization server (SEP-2352). **OAuth 2.0 Dynamic Client Registration is deprecated in favour of Client ID Metadata Documents (CIMD)** (PR #2858), with DCR kept for compatibility.
- **Extensions framework** (opt-in, vendor-prefixed ids, official ones live in `modelcontextprotocol/ext-*` repos):
  - **MCP Apps** — interactive UI inline in hosts (`io.modelcontextprotocol/ui`, mime `text/html;profile=mcp-app`); repo `ext-apps` **2,920★** (created 2025-11-21); overview https://modelcontextprotocol.io/extensions/apps/overview
  - **Skills over MCP** — repo `ext-skills` **729★** (created 2026-02-01)
  - **Tasks**, **OAuth Client Credentials**, **Enterprise-Managed Authorization** (repo `ext-auth` **167★**, last push 2026-06-18)
  - Experimental extensions use an `experimental-ext-` prefix.
- **Registry.** https://registry.modelcontextprotocol.io/ — official metadata registry (`server.json`, reverse-DNS namespaces, REST API + OpenAPI for downstream aggregators). Repo `modelcontextprotocol/registry` **7,329★**, **latest release v1.8.1 (2026-08-06)**; docs still label it **preview** ("breaking changes or data resets may occur"), backed by Anthropic, GitHub, PulseMCP and Microsoft.
- **SDKs** (stars 2026-10-08 / latest release): Python **24,508★ / v2.3.0 (2026-10-02)**; TypeScript **13,532★ / v2.3.1 (2026-10-05)**; Java **3,723★ / v2.0.1 (2026-08-19)**; Kotlin **1,464★**; Swift **1,508★**; Ruby **923★ / v1.7.0 (2026-10-05)**; Inspector **11,040★**. Tier 1 (TS, Python, Go, C#) all speak `2026-07-28` on release day; Rust SDK was in beta at that date.
- **Adoption (provider-stated):** >10,000 active public servers and 97M+ monthly SDK downloads (Anthropic, 2025-12-09); "close to half-a-billion downloads a month" across Tier 1 SDKs, with TS and Python SDKs past **1B total downloads** (MCP blog, 2026-07-28). Endorsement quotes on that release from AWS Bedrock AgentCore, Cloudflare, Google Cloud, Microsoft Foundry, Anthropic, Netlify, Supabase, Honeycomb ("nearly 20% of all monthly interactive queries are now made by agents").
- **Governance/roadmap:** donated to AAIF (LF) on 2025-12-09 with governance unchanged; the **2026 roadmap (2026-03-09)** dropped release-based milestones for **four priority areas** — transport evolution & scalability, agent communication, governance maturation, enterprise readiness — with Working Groups driving timelines; "On the Horizon" includes DPoP (SEP-1932) and Workload Identity Federation (SEP-1933).

### 1.2 A2A (Agent2Agent) — Google → Linux Foundation → Agentic AI Foundation
- **Canonical:** https://a2a-protocol.org/latest/specification/ · repo https://github.com/a2aproject/A2A (**26,073★**, pushed 2026-10-08, created 2025-04)
- **Versions:** **v1.0.0 released 2026-03-12** (16:34:41Z), **v1.0.1 released 2026-05-28** (11:34:36Z); prior line v0.3.0 (2025-07-30). The spec states "Version 1.0.0" and mandates a `Version: 1.0` header.
- **v1.0 content** (per AAIF's announcement): multi-protocol bindings and version negotiation, multi-tenancy, and **signed agent cards** for cryptographic identity verification.
- **Governance timeline:** launched by Google **April 2025**; donated to the **Linux Foundation 2025-06-23** ("more than 100 leading technology companies"); **moved under the AAIF on 2026-08-17**, where it is now "backed by over 150 organizations". IBM/BeeAI's **Agent Communication Protocol merged into A2A (Aug 2025)** — the i-am-bee/acp repo states "archived by the owner on Aug 27, 2025" and its docs site now reads "ACP is now part of A2A under the Linux Foundation!".
- **Adopters named by AAIF (2026-08-17):** Huawei (A2A standardised between Celia and in-app agents on HarmonyOS), Tencent WeChat (assistant-initiated messages/calls over A2A with dual authorization), Google Cloud (ADK, Agent Engine, Cloud Run, GKE), Microsoft Azure AI Foundry (expose/discover A2A endpoints), AWS Bedrock AgentCore, plus Google Cloud + PayPal extending A2A into agentic commerce via AP2.
- **SDKs:** Python (`a2a-sdk`), Go (`a2aproject/a2a-go`), JS (`@a2a-js/sdk`), Java, .NET, Rust (`a2a-lf`) — listed in the repo README (fetched 2026-10-08).
- **Reality check:** governance consolidation has not removed scepticism — HN's "Ask HN: Is anyone using the A2A protocol?" (2026-06-18, 96 points) is the visible symptom.

### 1.4 Other 2026 protocols and interop rails
- **Agent Client Protocol (ACP)** — Zed; https://agentclientprotocol.com/. Standardises editor↔coding-agent communication (JSON-RPC over stdio locally; HTTP/WebSocket for remote, still "work in progress"; reuses MCP JSON representations, adds diff/UX types; Markdown as default text format). Repo **4,391★** (created 2025-06-23). First surfaced on HN 2025-08-30.
- **A2UI** — https://a2ui.org/ (repo `a2ui-project/a2ui`, **16,629★**, created 2025-09-24). Agent emits declarative UI (surfaces + components + data binding) that clients render with native widgets (Angular/Flutter/React/Lit); spec versions **v0.8 legacy, v0.9 stable, v0.9.1 current, v1.0 candidate**; works with ADK and AG-UI-style harnesses; public "A2UI Composer". HN front page 2025-12-16.
- **AGNTCY (Cisco, LF Projects)** — https://agntcy.org/. Open-source "Internet of Agents" stack: Directory (federated discovery), **SLIM** network-level messaging, Identity, Observability, Evaluation, Secure Runtime, and **AgentBridge** (connects coding agents/CLIs over A2A). Its schema layer is **OASF** — `agntcy/oasf` **338★**, **v1.1.0 released 2026-07-10**.
- **NLWeb (Microsoft)** — https://github.com/nlweb-ai/NLWeb (**6,255★**, MIT, pushed 2026-08-11). Schema.org-based natural-language endpoints; **every NLWeb instance is also an MCP server** (A2A "soon"); components include `AskAgent`, `AgentFinder` discovery and `NLWebScorer`. Positioning: "NLWeb is to MCP/A2A what HTML is to HTTP."
- **AGENTS.md** — OpenAI-originated instruction file, an AAIF founding project (2025-12-09). Became a cross-vendor convention during 2026: Vercel "AGENTS.md outperforms skills in our agent evals" (2026-01-29), arXiv 2602.11988 (2026-02-16), Claude Code starts reading AGENTS.md when no CLAUDE.md exists (2026-09-18).
- **Agent Skills** — https://agentskills.io/ (HN front page 2026-02-03) plus MCP's `ext-skills`; a skills leaderboard (skills.sh, 2026-01-20) and skills benchmark (SkillsBench, arXiv 2602.12670) appeared within weeks; OpenClaw's ClawHub skills marketplace became an attack surface (see Open problems).
- **AAIF-hosted infra standards** — **agentgateway** (secure connections between agents, models, tools and APIs) and **Agent Router** (Envoy-based AI gateway), listed with MCP, goose, AGENTS.md and A2A at https://aaif.io/projects.
- **MCP-B** (browser automation over MCP, 2025-07-09) exists but is outside vendor governance.
