# Agent Interoperability Protocols & the 2026 Agent Landscape Timeline

_Research date: 2026-10-08. Every version, date and count below was fetched live during this session. Fetch status is listed in **Sources fetched**._

## Key findings (2026)

**Protocols**
- **MCP's current spec revision is `2026-07-28`** ("stateless protocol core": MRTR, header routing, cacheable list results, formal extension framework). Prior revisions: `2025-11-25`, `2025-06-18`, `2025-03-26`, `2024-11-05` — source: https://modelcontextprotocol.io/specification/ and its changelog (fetched 2026-10-08). GitHub release tag `2026-07-28` published 2026-07-28T16:47:49Z.
- MCP went **stateless** in 2026: the `initialize` handshake, `Mcp-Session-Id` sessions, SSE resumability, `ping`, `logging/setLevel` and `roots/list_changed` were removed, replaced by per-request `_meta` (`io.modelcontextprotocol/protocolVersion`, `clientCapabilities`), a mandatory **`server/discover`** RPC and a long-lived **`subscriptions/listen`** stream (SEP-2575). Roots/Sampling/Logging are **deprecated** with a ≥12-month window (SEP-2577/2596) — https://modelcontextprotocol.io/specification/2026-07-28/changelog (fetched 2026-10-08).
- MCP is **no longer Anthropic-owned**: donated 2025-12-09 to the **Agentic AI Foundation (AAIF)**, a Linux Foundation directed fund co-founded by Anthropic, Block and OpenAI (support: Google, Microsoft, AWS, Cloudflare, Bloomberg) — https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation , https://aaif.io/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation-aaif-anchored-by-new-project-contributions-including-model-context-protocol-mcp-goose-and-agents-md/ (fetched 2026-10-08).
- MCP scale (provider-published): **>10,000 active public servers and 97M+ monthly SDK downloads** (2025-12-09); **~500M Tier-1 SDK downloads/month with TypeScript and Python SDKs past 1B total downloads** (2026-07-28) — sources as above + https://blog.modelcontextprotocol.io/posts/2026-07-28/ (fetched 2026-10-08).
- **A2A reached v1.0.0 on 2026-03-12** (v1.0.1 on 2026-05-28) and **moved under the AAIF on 2026-08-17** (150+ partner organizations). IBM/BeeAI's competing **Agent Communication Protocol (ACP) merged into A2A in Aug 2025** (repo archived 2025-08-27) — https://api.github.com/repos/a2aproject/A2A/releases , https://aaif.io/blog/a2a-joins-aaif , https://github.com/i-am-bee/acp (fetched 2026-10-08).
- **Agent payments fragmented and then re-consolidated at FIDO**: Google's **AP2 v0.2.0 (2026-04-28)** was contributed to the **FIDO Alliance on 2026-04-28** (Agentic Authentication TWG chaired by CVS Health, Google, OpenAI); Stripe published the **Machine Payments Protocol (MPP, 2026-03-18)**; Google+Shopify launched the **Universal Commerce Protocol (UCP, Jan 2026)**, which is explicitly AP2-compatible; OpenAI+Stripe's **Agentic Commerce Protocol** (agenticcommerce.dev) remains the ChatGPT checkout standard — https://fidoalliance.org/fido-alliance-to-develop-standards-for-trusted-ai-agent-interactions/ , https://stripe.com/blog/machine-payments-protocol , https://ucp.dev/documentation/ucp-and-ap2/ , https://agenticcommerce.dev/ (fetched 2026-10-08).
- **"ACP" is genuinely ambiguous** across three live specs: Agent Communication Protocol (IBM/BeeAI, retired into A2A), **Agent Client Protocol** (Zed, editor↔coding-agent, 4,391★) and **Agentic Commerce Protocol** (OpenAI/Stripe). AAIF's 2026-10-06 post is literally titled "There Is No One Agentic Commerce Protocol" — https://aaif.io/blog/there-is-no-one-agentic-commerce-protocol (fetched 2026-10-08).
- New 2026 protocol entrants: **A2UI v0.9.1** (agent-driven UI, 16,629★), **UCP** (3,416★), **Visa Trusted Agent Protocol** (212★), **Stripe MPP**, and AAIF-hosted **agentgateway** / **Agent Router**.
